# Relais (versions à installer)

Relais pour Mac : publie des messages et des questions sur un serveur Relais, et rend la réponse par une notification.
macOS 14 ou plus, Mac à puce Apple. Aucun compte, aucune télémétrie.

Installer ou mettre à jour (vérifie l'empreinte SHA-256 et la signature) :

```
curl -fsSL https://raw.githubusercontent.com/LucasHRCHatReply/relais-releases/main/installer.sh | zsh
```

Les versions sont dans l'onglet Releases ; l'app les propose elle-même (onglet Mises à jour).
